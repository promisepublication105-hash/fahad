# কলেজ সহকারী চ্যাটবট (ডেমো)

A demo Q&A chatbot for a college, in Bangla and English. It answers from text
crawled from the college website. It runs fully in the browser, with no server
and no API key.

## ব্যবহার / Usage

1. **ওয়েবসাইট থেকে তথ্য সংগ্রহ / Collect the website's content**

   ```bash
   pip install requests
   python hollyland_chatbot/scrape.py https://www.hollylandcollege.com
   ```

   This crawls up to 40 pages on the same site and writes `knowledge.js`.

2. **চ্যাটবট খুলুন / Open the bot:** double-click `index.html`, or open it
   in any browser.

## Files

| File | Purpose |
|---|---|
| `index.html` | Chat UI and answer logic (keyword topics + passage search) |
| `topics.json` | Topics: keywords for matching, labels for quick buttons, fallback answers |
| `knowledge.js` | Generated by `scrape.py`; the copy committed here is demo data only |
| `scrape.py` | Crawls the site and builds `knowledge.js` |

## How it answers

1. Greetings and thanks get a fixed reply.
2. Otherwise the question is matched to a topic (ভর্তি, বেতন, যোগাযোগ…). The
   topic's keywords are added to the question, and the best-matching passages
   from the website are shown with a link to the source page.
3. If nothing was scraped yet, the topic's placeholder answer is shown, marked
   "ডেমো".

## Note

`www.hollylandcollege.com` did not resolve (it has no public DNS record) when
this was built, so the committed `knowledge.js` contains **no real college
information**. Run `scrape.py` with the correct website address to fill it.
